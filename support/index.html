Support

Questions about Cuvayo, a purchase, or your data? Send a private request below.

App currently in testing. Free tools remain available when cloud features are unavailable. Pro previews and purchases require the App Store and backend setup to be complete.

A few things you can do right away

  • Purchase missing? Open Settings → Restore purchases in Cuvayo. Use the same Apple Account used for the purchase.
  • Need to cancel? Manage your subscription in Apple’s subscription settings. Removing the app does not cancel it.
  • Export locked? Preview creations that use Pro features require a paid Pro subscription. Free-only creations can export without a subscription.
  • Need an Apple refund? You can request one through Apple’s Report a Problem. Apple determines refund eligibility.

Send a private request

Include the feature you were using, your iOS version, and what happened. For privacy requests, describe the data and action you are requesting. Please do not include passwords, API keys, payment-card numbers, or sensitive episode content.
